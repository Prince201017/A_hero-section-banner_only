## Suggested route structure

Do not implement everything on the root route.

Use independent routes or isolated preview states:

experiments/identity
experiments/chrome
experiments/type
experiments/product
experiments/motion
experiments/aperture
experiments/material
experiments/campaign
experiments/construction
experiments/quiet

The root route can eventually become a very small experiment index.

## Selection rule

A new experiment should be added only if it introduces at least one new:

- visual behavior
- interaction pattern
- material treatment
- typographic behavior
- composition system
- brand storytelling technique

Do not add another experiment merely because it looks different.

## Naming

Prefer names that describe the visual concept.

Good:

Chrome Surface
Material Scanner
Identity Lockup
Quiet Brand

Avoid:

Cool Section
Amazing Hero
Modern UI
Premium Card
New Design 2

## Final objective

The repository should eventually feel like a digital brand laboratory containing many small, highly art-directed pieces.

A visitor should be able to open one experiment, understand the idea almost immediately, interact with it, and leave with a visual impression.

The project does not need to become a massive website.

It needs to become a collection of things worth looking at.
